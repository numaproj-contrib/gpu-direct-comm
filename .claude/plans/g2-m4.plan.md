# Plan: FQDN 格納を Label から Annotation に移行する

**Source PRD**: `.claude/prds/g2.prd.md`
**Selected Milestone**: 4 — FQDN 格納を Label から Annotation に移行する
**Complexity**: Medium

## Summary

ADR-003 に基づき、vertexDomain FQDN の格納場所を Label から Annotation に変更する。Label はフィルタリング用マーカー（値 `"true"`）に限定し、FQDN の実データは Annotation に格納することで、Label 変更・削除時にも finalizer が確実に DNS レコードを削除できるようにする。併せて VertexDomainMutator に `+kubebuilder:webhook` マーカーを追加し、`make manifests` でのマニフェスト自動生成パイプラインに統合する。

## Tasks

### Task 1: 定数定義の変更と BuildVertexDomain の 63 文字制限削除

- **Action**: `internal/webhook/v1alpha1/vertex_domain.go` を更新
  - `LabelVertexDomain` 定数はキー名を維持（`gpu-direct-comm.numaproj.io/vertex-domain`）。Label の値は webhook 側で `"true"` を設定する（定数は `LabelVertexDomainValue = "true"` を追加）
  - `AnnotationVertexDomainFQDN` 定数を追加: `gpu-direct-comm.numaproj.io/vertex-domain-fqdn`
  - `maxLabelValueLength` 定数と 63 文字制限チェックを `BuildVertexDomain` から削除（FQDN は Annotation に格納されるため長さ制限不要）
- **Mirror**: 既存の定数定義パターン（`vertex_domain.go:24-33`）
- **Validate**: `go build ./internal/webhook/...` が成功すること

### Task 2: BuildVertexDomain テストの更新

- **Action**: `internal/webhook/v1alpha1/vertex_domain_test.go` を更新
  - 63 文字制限のテストケースを削除
  - 既存の正常系・エラー系テストはそのまま維持
- **Mirror**: table-driven テストパターン
- **Validate**: `go test -race ./internal/webhook/v1alpha1/...` が PASS すること

### Task 3: VertexDomainMutator の Annotation 移行 + `+kubebuilder:webhook` マーカー追加

- **Action**: `internal/webhook/v1alpha1/vertex_domain_mutator.go` を更新
  - Label `LabelVertexDomain` の値を `"true"` に設定（マーカー化）
  - Annotation `AnnotationVertexDomainFQDN` に FQDN を設定
  - `+kubebuilder:webhook` マーカーを追加:
    ```
    // +kubebuilder:webhook:path=/mutate-v1-pod-vertex-domain,mutating=true,failurePolicy=ignore,sideEffects=None,groups="",resources=pods,verbs=create,versions=v1,name=mvertexdomain.numaproj.io,admissionReviewVersions=v1
    ```
  - 注意: `objectSelector` は `+kubebuilder:webhook` マーカーでは直接サポートされないため、`make manifests` 後に kustomize patch で対応するか、マニフェストに手動パッチが必要かを確認する
- **Mirror**: `pipeline_mutator.go:32` のマーカーパターン
- **Validate**: `go build ./internal/webhook/...` が成功すること

### Task 4: VertexDomainMutator テストの更新

- **Action**: `internal/webhook/v1alpha1/vertex_domain_mutator_test.go` を更新
  - パッチ結果の検証を変更: Label の値が `"true"` であること、Annotation に FQDN が設定されていることを検証
  - 既存のスキップ系テストケース（非 Vertex Pod、binding なし等）はそのまま維持

- **Validate**: `go test -race ./internal/webhook/v1alpha1/...` が PASS すること

### Task 5: VertexDomainReconciler の FQDN 取得元変更

- **Action**: `internal/controller/vertexdomain_controller.go` を更新
