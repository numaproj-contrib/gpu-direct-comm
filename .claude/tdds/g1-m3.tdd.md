# TDD Report: G1-M3 — Pipeline edge ↔ numaNetwork 束縛の宣言と検証（ValidatingWebhook）

## 1. User Journeys

1. **束縛なし Pipeline は素通りする**
   As a platform engineer, I want existing numaflow Pipelines without the binding annotation to be admitted without any change, so that adding the webhook is non-breaking.

2. **有効な束縛 Pipeline は受理される**
   As a GPU workload developer, I want to annotate a Pipeline with `gpu-direct-comm.numaproj.io/numa-network-edges` to declare which edge uses which numaNetwork, so that the webhook validates and admits my Pipeline.

3. **不正な束縛は即座に拒否される**
   As a GPU workload developer, I want clear error messages when my binding annotation is malformed (broken JSON, invalid connectionType, non-existent edge, non-existent numaNetwork), so that I can quickly fix issues without cluster trial-and-error.

**クラスタ準備**:
