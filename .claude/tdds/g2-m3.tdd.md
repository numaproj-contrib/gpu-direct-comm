# TDD Report: G2-M3 — vertexDomainController が CoreDNS に DNS レコードを CRUD する

## 1. User Journeys

- **Vertex Pod の DNS 自動登録**: Pod が `LabelVertexDomain` ラベル付きで作成されると、ResourceClaim から Second NIC IP を取得し、CoreDNS 用 etcd に DNS A レコードを自動登録する
- **Vertex Pod 削除時の DNS クリーンアップ**: Pod が削除されると、finalizer により DNS レコードが確実に削除される
- **IP 未割当時の待機**: DRA ドライバがまだ IP を割り当てていない場合、コントローラは Requeue して待機する

1. ラベルの有無による分岐（skip vs 処理続行）
