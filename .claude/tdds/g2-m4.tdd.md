# TDD Report: G2-M4 — FQDN 格納を Label から Annotation に移行する

## 1. User Journeys

- As a Platform Engineer deploying a Numaflow Pipeline, I want the vertexDomain FQDN to be stored in a Pod annotation instead of a label, so that finalizer-based DNS cleanup works reliably even when labels are modified or deleted.
- As a contributor, I want the VertexDomainMutator webhook to be generated by `make manifests` via `+kubebuilder:webhook` markers, so that the webhook configuration is maintainable and consistent with the rest of the project.

## 2. Task Report

**Execution Log**

```

      operator: Exists
    - key: numaflow.numaproj.io/vertex-name
      operator: Exists
```

手書きマニフェストから自動生成 + kustomize patch への移行が完了し、マニフェスト生成パイプラインに統合された。
